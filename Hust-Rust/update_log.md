# Hust-Rust 更新日志

--------------------
**日期**: 2026-06-23
**版本**: v0.1.10+20260623

### 新增特性

1. **保留用户声明的变量类型**
   - for 循环变量不再硬编码为 usize/i32，保留用户声明的原始类型（i8/i16/i32 等）

2. **数组索引自动适配 Rust**
   - 新增 Rule 18，自动为变量索引添加 `as usize` 转换
   - 示例：`scores[i]` → `scores[(i) as usize]`
   - 字面量索引（如 `scores[5]`）和切片（如 `scores[0..5]`）不受影响

### Bug 修复

1. **递减循环 `i>=0; i--` 支持**
   - 之前自动转 usize 导致 `i>=0` 永远为真、`i=0; i--` 溢出 panic
   - 现在使用用户声明的有符号类型，递减循环正常退出

2. **注释后跟花括号编译错误**
   - 问题：`// 注释}i = i + 1;}` 中 `}` 被行注释吞并
   - 解决：for 循环体多行格式化，更新语句在独立行

--------------------
**日期**: 2026-06-13
**版本**: v0.1.8+20260613

### 新增特性

1. **for 循环代码块更新支持**
   - 支持在 for 循环更新部分使用代码块形式
   - 示例：`for (i16 i=0; i<3; { i++; count++; other--; }) { ... }`
   - 体现了 Hust 语言的包容性和"以块为单元"的设计思想
   - 需要在代码块中包含循环变量的更新

### 重构改进

1. **for 循环标记方法重构**
   - 使用标记方法（###HUST_PREFIX###、###HUST_POSTFIX###）处理前缀/后缀操作符
   - 更安全的转译过程，确保信息正确传递和清理
   - 提升代码可维护性和扩展性

2. **代码组织优化**
   - 更新 Hust设计指引.md，记录"以代码块为单元的组织设计思想"
   - 更新 Hust语法规则.txt，明确 for 循环代码块更新的规范

--------------------
**日期**: 2026-05-24
**版本**: v0.1.6+20260524

### 修复内容

1. **for 循环转换优化**
   - 简单条件如 `i < n` 转换为 Rust 原生 `for i in 0..n`
   - 复杂条件如 `(i*i <= n)` 转换为 while 循环

2. **修复 while 循环递增 BUG**
   - 问题：更新语句 `i = i + 1` 未添加到 while 循环体
   - 解决：将更新语句插入 while 循环体的开头

3. **修复转换顺序问题**
   - 问题：`for (i = 2; i*i <= n; i++)` 转换为 `for ((i16 i) = 2; ...)`
   - 原因：变量声明转换在 for 循环转换之后执行
   - 解决：调整转换顺序，for 循环转换优先于变量声明

4. **修复数组声明双分号 BUG**
   - 问题：`i16[4] numbers = {1,2,3,4};` 转换后产生 `;;`
   - 原因：正则表达式未匹配末尾分号
   - 解决：正则改为 `([^}]+)\};` 确保匹配完整声明

### 测试结果
- 质数判断测试通过：2 is true, 17 is true, 25 is false, 97 is true

1. **C风格类型转换 (r27)**
   - 支持 `(f32)sum` 转换为 `sum as f32`
   - 支持复杂表达式 `(i32)(a + b)` 转换为 `(a + b) as i32`
   - 转换为 Rust 的 `as` 操作符
